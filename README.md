Instructions

The tutorial is straight forward and doesn't need much guidance.

The main goal of each room is to reach the other end of the room.

If there is Vines blocking your progression they need to be destroyed with a barrel in order to progress.

Use the kill command to spawn a clone or player, buttons require a clone to stand on them in order to open gates or move platforms.

When a clone picks up an object you are able to stand on said object while the clone is carrying it, use that as a way to progress in the later stages of loop 2.


Cheat codes
Alt + R = reset player spawn
Alt + L = set lives to 30
Alt + T = teleport next to other side of room
Alt + N = go to next room
Alt + P = set lives to 1
Alt + Shift + (numbers 0-9) = teleports to the corresponding room
