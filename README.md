# Island_Stuck_In_Time

by Robert Valencia, and Cooper Adams



#Cheat Codes:

Alt + R: Teleport to spawn

Alt + L: Set lives to 30

Alt + T: Teleprt to finish line

Alt + N: Go to next room

Alt + P: Set lives to 1

Alt + Shift + [0 - 9]: Teleports to corresponding room number



#Game Theme
The project theme of 'TIme Loops' was implemented particularly with the inclusion of 'time clones'. Within the game you utilize snapshots of previous lives to assist you in solving certian tricky puzzles you encounter as you complete the game. Each 3 levels within the game is also a 'time loop', as you rewind to the original spawn of the levels each time you try to escape.
